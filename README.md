# 🌻 마음 돋보기 (Mind Lens) - 행동 활성화(BA) & 동적 네트워크 임상 시스템

행동 활성화(Behavioral Activation, BA) 기법과 네트워크 심리측정학(Network Psychometrics)을 기반으로, 내담자의 일상 스트레스 행동 연쇄를 분석하고 맞춤 긍정 대처를 제안하는 웹 애플리케이션입니다.

---

## 🌟 주요 특징

- **내담자-상담자 원격 분리 구조**:
  - **내담자 앱 (`app.html` / `client.html`)**: 스마트폰이나 개인 기기에서 간편하게 8단계 설문(컨디션 ➔ 계기 ➔ 생각 ➔ 감정 ➔ 신체반응 ➔ 회피행동 ➔ 결과 ➔ 긍정대처)을 작성하고 마음 지도와 맞춤 편지를 확인합니다.
  - **상담자 콘솔 (`admin.html`)**: 내담자들이 제출한 데이터를 실시간으로 수신하여, D3.js 기반 전이 네트워크 분석 지도와 Gemini 임상 자동 소견서를 열람합니다.
- **Firebase Firestore 클라우드 영구 DB 연동**:
  - 내담자와 상담자가 서로 다른 기기 및 브라우저에서 실시간으로 데이터를 공유합니다.
  - 내담자 등록 시 상담자 화면에 즉시 자동 반영 (`onSnapshot` 리스너).
  - 인터넷 단절 및 미설정 시에도 브라우저 IndexedDB / localStorage로 자동 안전 백업 (Zero-Downtime Fallback).
- **데이터 백업 및 마이그레이션 지원**:
  - 기존 로컬 브라우저 데이터 ➔ 클라우드 DB 원클릭 마이그레이션.
  - 전체 데이터 CSV 추출 및 JSON 덤프 지원.
  - 개별 세션 삭제 및 전체 초기화 지원.

---

## 🚀 빠른 시작

1. **내담자용 앱 실행**: 브라우저에서 `app.html` 또는 `client.html` 열기
2. **상담자용 콘솔 실행**: 브라우저에서 `admin.html` 열기
3. **클라우드 DB 연동**:
   - `FIREBASE_GUIDE.md`를 참고하여 Firebase 콘솔에서 무료 프로젝트를 만든 뒤,
   - `firebase-config.js`에 설정값을 넣거나 화면 상단의 **[클라우드 DB 설정]** 버튼을 통해 붙여넣기만 하면 실시간 동기화가 활성화됩니다!
